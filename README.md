# Factory Robot Hazard Analyzer System

## Factory Robot Hazard Analyzer System - Object-Oriented Programming Hazard Analyzer

A Java project that Analyzer evaluates the hazard risk score of a factory robot based
on:  
● Arm Precision  
● Worker Density  
● Machinery State  

## UC1: Display Static Hazard Message
Displays a static message indicating the purpose of the system.

## UC2: Accept Robot Hazard Inputs
Accepts inputs required for hazard analysis from the user.

## UC3: Calculate Hazard Risk Score (No Validation)
Calculates and displays the hazard risk score using the given formula.

## UC4: Introduce Validation Using Conditional Logic
Validates input ranges using if-else statements.

## UC5: Refactor Validation into a Separate Method
Moves hazard calculation and validation into a separate method.

## UC6: Introduce Custom Exception –
Handles invalid scenarios using a custom exception.

## UC7: Machinery State Risk Mapping
Handles machinery risk factors using structured logic.

## UC8: Fully Modular & OOPS-Compliant Hazard Analyzer
Deliver a clean, modular, and extensible hazard analysis system.

## How to Run
Compile using javac FactoryRobotHazardAnalyzerSystem.java and run using java FactoryRobotHazardAnalyzerSystem.
